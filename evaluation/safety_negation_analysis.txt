4. RESULTS AND ROOT CAUSES
--------------------------
Total test cases: 19 (positive A=5; clear negation B=6; third-person/quoted/informational C=4; mixed/ambiguous D=4).
Current explicit_safety=true: 18/19. On determinate expected values: false positives 10 (B=6, C=4); false negatives 1 (A5); expected=review 3 (D1, D2, D4), deliberately excluded from FP/FN; D3 is expected true and matched. These are synthetic regression examples, not measured error rates on real traffic.

- Simple substring: any occurrence anywhere in the lowercased text triggers, including embedded matches inside negations, quotes, and references to another person. Overlapping phrase entries do not resolve context.
- Thai negation: ไม่, ไม่ได้, แล้ว, and double-negation constructions can alter current intent while leaving the positive phrase intact. A single preceding ไม่ได้ is not a reliable safety verdict; D3 shows a denial can be followed by a current thought.
- Quoted/third-person context: C1-C4 show the matcher cannot distinguish a user's own current statement from reported speech, a definition question, or informational reading. A third-person report can still warrant help for that person; expected=false is limited to the user's own explicit crisis matcher.
- Temporal context: B5 and D1 include past/current contrasts. B5 is a direct current denial, whereas D1 is held for review because the past risk remains contextually relevant. Neither should be called clinically safe from this rule alone.
- Mixed intent/boundaries: D2-D4 combine negation with hopelessness, a later admission, or life-circumstance wording. Blanket exclusion would risk suppressing D3 and similar disclosures.
- Lexical gap: A5 is a direct self-directed statement without a configured phrase. The independent ML paths might still identify it, but this test did not run them.

5. MINIMAL FIX OPTIONS (PROPOSALS ONLY; NONE IMPLEMENTED)
----------------------------------------------------------
Option A — Negation-aware exclusions near a matched phrase.
Complexity: low to medium for a small curated set of clear denials. False-negative risk: HIGH if a negation anywhere before a phrase suppresses D3 or a later clause. Maintainability: initially simple but fragile as Thai expressions vary. Recommendation: do not use as a blanket stand-alone rule; only suppress tightly defined, unambiguous whole statements with regression tests.

Option B — Regex/clause context window for negation, quotation, speaker, and time markers.
Complexity: medium to high because Thai spacing, compound clauses, and reported speech vary. False-negative risk: MEDIUM to HIGH if a context window incorrectly spans a later admission. Maintainability: moderate to poor without a growing labeled regression matrix. Recommendation: consider only if tests show a bounded pattern set; do not treat a preceding ไม่ได้ as sufficient by itself.

Option C — Dedicated conservative safety-matching helper with explicit outcomes for direct match, clear contextual/negated reference, and unresolved mixed content.
Complexity: medium; the change can stay localized to the explicit rule without changing ML thresholds or the 2Q/9Q/8Q flow. False-negative risk: lower than A/B if only unmistakable denials/informational references suppress direct matching and mixed cases retain safety-oriented handling or request clarification. Maintainability: better because context rules and test cases live together. Recommendation: preferred minimal direction after human/safety review. Preserve current risk_is_high and intent_is_crisis OR paths; never map an unresolved case to safe by default.
